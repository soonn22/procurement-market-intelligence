# procurement-market-intelligence



\# Procurement Analytics Portfolio

\*\*Nexus Manufacturing Inc. | SAP S/4HANA MM Environment | 2023–2025\*\*



\## Overview

This portfolio demonstrates applied procurement analytics capability using SAP S/4HANA-style data. 

Built by Seungsoon Park, Supply Chain \& Procurement Professional.



\## Dashboards

Six-page Power BI dashboard covering:

\- Spend Overview

\- Supplier Spend Analysis

\- Supplier Performance KPI

\- Supplier Scorecard

\- Kraljic Portfolio Analysis

\- Invoice \& Payment Analysis



\## Data Sources

All data simulates a real SAP S/4HANA MM environment export.



| File | SAP Transaction | Records | Description |

|---|---|---|---|

| NX\_MM\_PO\_LineItems\_ME2M.csv | ME2M | 2,430 | PO line items with GR dates and delivery status |

| NX\_FI\_VendorLineItems\_FBL1N.csv | FBL1N | 2,400 | Vendor invoice line items with payment status |

| NX\_MM\_VendorMaster\_XK03.csv | XK03 | 40 | Vendor master with contract status and spend tier |



\## Key Findings

\- Total spend: $131.8M across 40 suppliers and 8 categories (2023–2025)

\- OTD rate: 90.33% — 5 suppliers below 85% threshold

\- On-contract rate: 79.75% — $24.8M in off-contract spend across 5 suppliers

\- On-time payment rate: 70.83% — $11.7M in overdue invoices

\- Kraljic analysis: 7 Leverage suppliers representing $67M in competitive bidding opportunity

\- Precision Instruments identified as sole Strategic supplier — off-contract, highest priority for negotiation
